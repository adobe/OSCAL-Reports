AWS Architecture for OSCAL (AI via Bedrock)

Typical Setup Cost

~$35–50/month base

Green + Blue t3.small (always on) | S3 (logs, config, users) | Bedrock pay-per-use for AI

Design: ALB routes to Green (3019) and Blue (3020). Config and users live in S3; instances sync/mount from S3. AI suggestions use AWS Bedrock (no self-hosted Ollama). All resources tagged (Project, Environment, Stack) for easy add/remove per account.
